# Privacy

Scéal is currently designed as a local-first macOS notes app.

## Current Behavior

- Scéal does not require an account.
- Scéal stores notes locally on the user's Mac.
- Scéal does not sync notes to a hosted service.
- Scéal does not include analytics, advertising SDKs, or third-party tracking SDKs.
- Scéal reads and writes user-selected files only for import, export, backup, restore, and attachment workflows.

## Data Stored Locally

Scéal stores note content, list-note groups, image attachments, appearance preferences, and backup settings on the user's Mac. See [Data storage](data-storage.md) for paths and file formats.

## Distribution Notes

If Scéal later adds paid features, licensing, crash reporting, analytics, cloud sync, newsletter signup, or a website download flow, this privacy document and any App Store privacy answers must be updated before release.

For Mac App Store distribution, Apple requires a Privacy Policy URL for all apps. See Apple's [App privacy reference](https://developer.apple.com/help/app-store-connect/reference/app-information/app-privacy/).
